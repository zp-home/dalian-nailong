01 / ABOUT THE SCHOOL

一所把「先跑起来，再变优雅」写进院训的脑洞学院。

我们把软件工程的学习日常变成校园脑洞：一起拆解需求、设计界面、写下代码，也认真对待每一次「为什么在我电脑上可以运行」。

从一个好用的小工具，到一款能让同学会心一笑的应用，项目始终是主角。组队时可以带零食，但请记得带上清晰的思路，以及愿意一起找 Bug 的耐心。

在奶龙的想象里，软件工程不是背下来的语法，而是「把想法变成别人真的能用起来的东西」的完整过程：先问清楚谁需要它，再画草图、写代码、找同学试用，最后老老实实写一份别人看得懂的 README。

02 / COURSE LIST

三门想象中的课程

课程名称与考核方式均为趣味虚构，
不对应真实的培养方案或学分安排。

COURSE 01

面向奶龙的程序设计

从 print("Hello, 奶龙") 开始，理解变量、循环与函数，也理解「为什么它又不运行」。

趣味考核：让程序对着教室说一句你好

COURSE 02

Bug 追踪与情绪稳定

学会读报错、缩小范围、验证猜想，也学会在第三次失败之后，仍然愿意再看一眼。

趣味考核：独立解决一个自己造的 Bug

COURSE 03

从零到一的校园应用工坊

组队把一个真实的小需求做成能用的页面或工具，从草图到上线走完整个流程。

趣味考核：交一份别人看得懂的 README

以上课程、考核方式与「学院」均为原创虚构设定，不对应大连东软信息学院或任何学校的真实教学安排。

04 / STUDENT WORKS

学生作品角

以下作品均为趣味设定，
用来解释「项目才是主角」的学习方式。

PROJECT 01

校园午饭选择器

三秒帮整个宿舍决定中午吃什么，并诚实地保留「今天不吃食堂」这个选项。

PROJECT 02

空教室探测仪

用想象中的传感器找一间安静的教室，顺手把异步与缓存真正搞明白一次。

PROJECT 03

奶龙表情包生成器

把同学的名字变成一只会说话的表情包，练习 SVG 绘制与字符转义。

05 / GRADUATION

奶龙式毕业要求

THE ONLY RULE
做出一个自己愿意每天使用的小作品，并让另一只奶龙看懂你的 README。

这是奶龙大学独有的趣味标准，与真实学校的毕业要求、学分与学位规定没有任何关系。它的意思其实很朴素：作品要真的被用过，说明要真的被看懂。
