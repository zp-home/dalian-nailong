01 / ABOUT THE SCHOOL

一所把「说错也没关系」写进课堂规则的脑洞学院。

我们把语言学习想象成一次持续发生的交流：介绍自己的城市，也认真听见不同的文化与生活。开口的勇气，比语法的正确更值得先被表扬。

练习从来不只在单词本里。为一位远方的朋友设计校园路线，给自己的作品写一段外语介绍，或一起讨论一个有趣的话题，都是迈向世界的小小一步。

我们也会聊聊语言背后的东西：为什么同一句话在不同文化里轻重不同，以及怎样在表达自己的同时，也照顾好对方的感受。

学院院训先微笑，再开口。

02 / COURSE LIST

三门想象中的课程

课程名称与考核方式均为趣味虚构，
不对应真实的培养方案或学分安排。

COURSE 01

用外语介绍一只奶龙

从最简单的句子开始，把最熟悉的东西讲给完全陌生的人听。

趣味考核：录一段两分钟的自我介绍

COURSE 02

跨文化交流与校园故事

练习在不同文化语境里提问、回应与解释误会，而不是急着下结论。

趣味考核：为一个外国朋友设计一份校园导览

COURSE 03

技术作品的双语表达

给自己的项目写一份外语说明，让完全不懂中文的人也能把它用起来。

趣味考核：交出一份双语的 README

以上课程、考核方式与「学院」均为原创虚构设定，不对应大连东软信息学院或任何学校的真实教学安排。

04 / STUDENT WORKS

学生作品角

以下作品均为趣味设定，
用来解释「项目才是主角」的学习方式。

PROJECT 01

校园双语导览

把校园里最常去的地方，做成一份中英双语的小地图。

PROJECT 02

奶龙词汇卡

一套只收录「课本里不会教、但每天都要用」的词卡。

PROJECT 03

给远方朋友的一封信

用正在学的语言写一封信，然后真的把它寄出去。

05 / GRADUATION

奶龙式毕业要求

THE ONLY RULE
用正在学习的语言，完整分享一件让你感到自豪的小事。

这是奶龙大学独有的趣味标准，与真实学校的毕业要求、学分与学位规定没有任何关系。它的意思其实很朴素：能把一件小事讲完，就说明你已经开始用它生活。
