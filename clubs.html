02 / NSS

大连东软信息学院网络安全工作室

学校官方新闻里把它写作「我校网络安全工作室」，这篇新闻是它作为学校承认的技术型社团 / 工作室最直接的公开依据；它不是竞赛集训队。

关于名字只说一件事：NSS 三个字母的官方展开没有公开说明，所以本文只写「NSS（大连东软信息学院网络安全工作室）」，不替它编一个全称。它的自建站品牌写作 "NSS Cybersecurity Lab"。

它公开的方向有六个：Web 安全、二进制安全（PWN）、逆向工程、网络攻防、安全开发、CTF 与取证。这六项写在其官网的研究方向页上，属于组织自己的表述。

一句话认识它打 CTF、做攻防的那群人。

04 / SHIMMER

微光网络工作室

如果要用一句话介绍微光，那就是：学校官网的开发者。学校官网首页的页脚署名「网站策划：品牌发展部」，新闻内页的页脚写着「技术支持：微光网络工作室」——微光承担着学校官网的技术开发与维护。

它的官网自述是一支「大连东软信息学院 Web 兴趣团队」，成员不足十人，没有等级之分。官网的「微光Lab」板块列出了自己的作品：学校官网中文 / 英文 / 日文三语版本、新闻文化网、东软 Go 校内导航、掌上游东软、校庆答题 Neu Q&A、社团纳新工具 New Game、微信活动抢票系统、微光后院博客与 Shimmer Docs / Git。

它也是三个组织里唯一把自己放在学校官方域名之下的：官网地址是 shimmer.neusoft.edu.cn。GitHub 组织 NeuShimmer 有 9 个公开仓库，简介写着 "Shimmer Network Studio · A Web development group from DUNI"；另有 npm 组织 neushimmer。

一句话认识它写学校官网的那支小团队。

06 / ACM

ACM 编程爱好者社

它是人工智能学院的「专业社团」。它的来历写在学院官网的社团介绍页上：2010 年 3 月，学校首次受邀参加第三届 ACM-ICPC 辽宁省赛（在辽宁科技大学举行），派出 3 支队伍共 9 人，「东软1队」拿到辽宁省一等奖、院校排名第四——参赛回来之后，社团就成立了。

它的活动节奏是「每天的，不是定期才进行的」：新手培训、赛前集训、日常训练、社团内部竞赛，另外每年还有两次面向全校理工类大一的编程竞赛。参加过的赛事包括 ICPC 亚洲预赛、CCPC 全国赛、CCPC 东北四省区赛、蓝桥杯省赛与国赛、天梯赛。

老底子也够看：ICPC 亚洲赛两度铜奖（2014、2018）；蓝桥杯国赛多人次全国一等奖，最好成绩是全国第 8（一位 2010 级同学，排在当年所有东北高校选手之前）；天梯赛最好成绩（二本组）为国家级三等、东北地区二等、辽宁省一等奖。

一句话认识它2010 年创立、每天训练的老牌算法社团。
